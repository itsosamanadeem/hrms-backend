# Contributing to HRMS Backend

Thank you for your interest in contributing! By contributing to this repository, you agree to the following:

1. **Ownership**
   - The original code and repository remain the property of Osama Nadeem.
   - Contributions become part of this project, but contributors do **not claim ownership** of the original code.

2. **License**
   - All contributions are released under the **AGPLv3 license**.
   - Modifications or enhancements you make must comply with this license.

3. **Pull Requests**
   - Fork the repository, make your changes in a separate branch, and submit a pull request.
   - Pull requests are reviewed by the repository owner before merging.

4. **Respect and Collaboration**
   - Be respectful in discussions, follow coding standards, and provide clear commit messages.

Thank you for helping improve HRMS Backend!
